# Student Management System

## Description

Student Management System is a simple project designed to maintain student information. It helps organize student details in one place.

## Features

- Add student details.
- View student information.
- Update student records.
- Manage student data.
- Easy to use interface.

## Technologies Used

- Java
- MySQL
- GitHub
- Markdown

## Installation

Follow these steps to install the project:

1. Clone the repository.
2. Open the project folder.
3. Configure the required software.
4. Run the application.
